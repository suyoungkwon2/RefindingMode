## UT의 목적

1. 전후 비교: “검색형 유저의 재탐색 문제가 개선되었는가?”
    - 대상: 기존 유저 중 ‘검색형’ 사용자
2. 그룹별 비교: “검색을 자주 하지 않던 사람도 쉽게 사용하나?”
    - 대상: 새로운 사용자, 재탐색형 유저지만 '검색형' 유저가 아닌 유저 (질문/저장/혹은 아예 안하던..)
3. 추가 비교: "질문형 유저는 이 솔루션을 어떻게 느끼는가?"
    - 대상: 기존 유저 중 ‘질문형’ 사용자도 가능

## **평가 대상 프로토타입 기능**

| 약칭 | 기능 | 이 기능이 검증하려는 것 |
| --- | --- | --- |
| F1 | 자연어 검색바 | 정확한 키워드 없이 모호한 자연어 단서로 답을 찾을 수 있는가 |
| F2 | 스마트 스코프 칩 | 현재 세션/선택 세션/관련 주제/전체 등 검색 범위를 쉽게 좁힐 수 있는가 |
| F3 | 매칭 이유 태그 | 왜 이 결과가 나왔는지 보고 후보 간 관련성을 판단할 수 있는가 |
| F4 | 호버 프리뷰 | 결과 카드를 열기 전에 미리보기로 적합성을 빠르게 가릴 수 있는가 |
| F5 | 핀 분할 뷰(원본 재진입) | 선택한 답의 원본 위치로 정확히 이동해 맥락을 확인·재사용할 수 있는가 |
| F6 | 섹션 미니맵 | 긴 대화 안에서 답의 공간적 위치를 파악하고 이동할 수 있는가 |

## **그룹별 관찰 포인트**

| **그룹** | **UT에서의 핵심 질문** | **특히 관찰할 것** |
| --- | --- | --- |
| 검색형
(숙련) | 재탐색 문제가 ‘전후로’ 개선되는가? (핵심 가설 그룹) | Before에서 이미 능숙 → After가 그 효율을 더 높이는지. Cmd+F 습관으로 회귀하는지, 스코프 칩을 신뢰하는지 |
| not 검색형
(비숙련) | 검색을 잘 안 하던 사람도 쉽게 쓰는가? | Before에서 검색을 아예 시도하지 않거나 스크롤로 헤매는지. After의 발견가능성·진입장벽 감소, 자연어 검색바의 직관성 |
| 질문형
(1명, 정성) | 질문형 유저는 이 솔루션을 어떻게 느끼는가? | ‘찾기’ 대신 AI에 다시 질문하려는 경향이 있는지, 재탐색 도구를 채택하는지 vs 재질의를 고수하는지 |

## 태스크 설계

| **피험자(그룹 내)** | **1차 조건** | **2차 조건** |
| --- | --- | --- |
| P1 | Before · 세트 A | After · 세트 B |
| P2 | After · 세트 A | Before · 세트 B |
| P3 | Before · 세트 B | After · 세트 A |
| (여유 시) P4 | After · 세트 B | Before · 세트 A |

| **단계** | **시간**ㅈㅈ | **내용** |
| --- | --- | --- |
| 1. 도입·동의 | 5분 | 연구 목적/절차 설명, 녹화·데이터 수집 동의서 서명, think-aloud 방식 안내(‘도움은 드리지 않지만 사전 안내는 가능’) |
| 2. 사전 설문/분류 확인 | 5분 | AI 사용량·검색 습관 문항으로 그룹(검색형/not 검색형/질문형) 분류 재확인 |
| 3. 페르소나 브리핑·친숙화 | 5분 | 6장 커버스토리 낭독 + 아카이브 5–7분 훑기(얕은 인지 형성, 정답 암기 금지) |
| 4. 조건 1 태스크 수행 | 12~15분 | 배정된 인터페이스+세트로 5개 태스크 수행. 무개입 관찰, think-aloud, 태스크별 3분 제한, 지표 기록 |
| 5. 조건 1 사후 설문 | 5~7분 | NASA-TLX + 프로젝트 Likert 문항 |
| 6. 조건 2 태스크 수행 | 12~15분 | 다른 인터페이스+다른 세트로 동일하게 수행 |
| 7. 조건 2 사후 설문 | 5~7분 | NASA-TLX + Likert |
| 8. 비교·반구조화 인터뷰 | 10분 | 두 조건 직접 비교(선호와 이유), 그룹별 심화 질문(9장) |

## **태스크 세트**

<aside>
👉🏻

**두 개의 세트가 필요한 이유:** 피험자 내 설계에서 동일 정답을 두 번 찾게 하면, 두 번째 조건은 ‘이미 답을 알고 있는’ 오염된 측정이 된다. 이를 막기 위해 동등 난이도의 세트 A와 B를 만들고, 한 피험자에게 ‘Before에는 한 세트, After에는 다른 세트’를 배정한다. 같은 번호(A1↔B1 등)는 유형·범위·대상기능이 동형이다.

</aside>
